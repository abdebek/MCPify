# Contribution Guide

## Pull Request Target Branch

- Open all new pull requests against the `dev` branch.
- Do not target `main` for regular feature, fix, or refactor work.

## Release Channels

- Preview releases are based on the latest `dev` branch state.
- Stable releases are based on the `main` branch.

## Practical Workflow

1. Create your feature branch from `dev`.
2. Open your PR into `dev`.
3. After validation, changes flow from `dev` to `main` as part of the stable release process.
